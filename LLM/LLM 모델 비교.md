# 5. 답변 내용 요약

## 5.1 Gemini 2.5 Pro 답변 정리

### 1) 전체 답변 방향

- 내연기관차, 전기차, 하이브리드차를 각각 구분하여 설명하였다.
- 핵심 관점은 **동력원의 특성에 따라 필요한 변속 장치가 달라진다**는 것이다.
- 전체적으로 친절하고 이해하기 쉬운 설명 방식을 사용하였다.

### 2) 내연기관차 설명

- 동력 흐름:  
  **엔진 → 변속기 → 구동축 → 차동기어 → 바퀴**
- 연료 폭발로 피스톤의 왕복 운동이 발생한다.
- 피스톤의 왕복 운동은 크랭크축을 통해 회전 운동으로 변환된다.
- 엔진은 특정 RPM 구간에서만 효율과 토크가 좋다.
- 따라서 속도와 주행 상황에 따라 기어비를 바꾸는 다단 변속기가 필요하다.
- 저속에서는 큰 기어비를 사용하여 토크를 증폭한다.
- 고속에서는 작은 기어비를 사용하여 엔진 회전수를 낮추고 연비를 향상한다.

### 3) 전기차 설명

- 동력 흐름:  
  **배터리 → 인버터 → 전기모터 → 감속기 → 차동기어 → 바퀴**
- 배터리의 전기 에너지가 인버터를 거쳐 전기모터를 구동한다.
- 전기모터는 전기 에너지를 바로 회전 운동으로 변환한다.
- 정지 상태에서도 큰 토크를 발생시킬 수 있다.
- 넓은 RPM 범위에서 효율적으로 작동할 수 있다.
- 복잡한 다단 변속기가 필요하지 않다.
- 모터의 높은 회전수를 바퀴에 적합한 속도로 낮추기 위해 단일 감속기를 사용한다.

### 4) 하이브리드차 설명

- 엔진과 전기모터를 함께 사용하는 차량으로 설명하였다.
- 저속에서는 모터만 사용한다.
- 고속 주행에서는 엔진 중심으로 작동한다.
- 급가속 시에는 엔진과 모터가 함께 작동한다.
- 핵심 부품으로 동력 분기 장치 또는 e-CVT를 제시하였다.
- 동력 분기 장치는 엔진과 모터의 힘을 합치거나 나누는 역할을 한다.
- 주행 상황에 맞게 동력을 배분한다.

### 5) 답변의 특징

- 세 차량의 차이를 쉽고 균형 있게 정리하였다.
- 전기차가 단일 감속기를 사용하는 이유를 이해하기 쉽게 제시하였다.
- 하이브리드차가 동력 분기 장치를 사용하는 이유도 명확히 설명하였다.
- 다만 변속기 종류, 모터 종류, 하이브리드 방식의 세부 차이에 대한 설명은 부족하였다.
- 보고서에 바로 사용하기에는 일부 대화체 표현의 수정이 필요하였다.

## 5.2 Claude Haiku 4.5 답변 정리

### 1) 전체 답변 방향

- 세 모델 중 가장 시각적으로 정리된 답변을 제시하였다.
- 각 차량의 동력 흐름을 코드 블록 형태로 제시하였다.
- 표와 간단한 그래프를 사용하였다.
- 전체적으로 차량별 차이를 비교하기 쉬운 구성이었다.

### 2) 내연기관차 설명

- 동력 흐름:  
  **엔진의 왕복 운동 → 크랭크축 회전 → 다단 변속기 → 구동축 → 차동기어 → 바퀴**
- 엔진은 특정 RPM 구간에서만 효율적으로 작동한다.
- 저속에서는 토크가 부족할 수 있다.
- 최적 RPM 구간에서는 효율이 향상된다.
- 고속 RPM에서는 효율이 저하될 수 있다.
- 다단 변속기는 엔진의 좁은 효율 구간을 보완하기 위한 필수 장치이다.
- 기어별 기어비와 역할을 표로 제시하였다.

### 3) 전기차 설명

- 동력 흐름:  
  **배터리 → 인버터 → 전기모터 → 단일 감속기 → 차동기어 → 바퀴**
- 전기모터는 전자기력으로 회전자를 직접 회전시킨다.
- 0 RPM에서도 큰 토크를 발생시킬 수 있다.
- 모터와 엔진의 토크 특성을 간단한 그래프로 비교하였다.
- 모터의 특성상 다단 변속기가 필요하지 않다.
- 단일 감속기만으로 동력을 전달할 수 있다.
- 구조 단순화, 부품 수 감소, 유지보수 용이성을 장점으로 제시하였다.

### 4) 하이브리드차 설명

- 엔진과 전기모터를 함께 사용하는 구조로 설명하였다.
- 주행 상황별 작동 방식을 표로 정리하였다.
- 저속 출발 시에는 모터만 사용한다.
- 정상 주행 시에는 엔진 중심으로 작동한다.
- 급가속 시에는 엔진과 모터를 동시에 사용한다.
- 감속 또는 제동 시에는 회생제동을 통해 배터리를 충전한다.
- 유성기어 세트를 이용한 동력 분기 장치와 e-CVT의 역할을 제시하였다.

### 5) 답변의 특징

- 표, 흐름도, 그래프를 활용하여 가독성이 높았다.
- RPM, 기어비, 부품 수, 동력 손실률 등 구체적인 수치 예시를 포함하였다.
- 하이브리드차의 주행 모드와 유성기어 구조 설명이 기계공학적 이해에 도움을 주었다.
- 다만 일부 수치에는 출처가 없어 신뢰성 검토가 필요하였다.
- 이모지와 대화체 표현이 있어 보고서용 문체로 수정할 필요가 있었다.

## 5.3 GPT-5 답변 정리

### 1) 전체 답변 방향

- 세 모델 중 가장 기계공학적으로 구체적인 답변을 제시하였다.
- 핵심 관점은 다음과 같다.

> 동력원의 특성 → 변속 또는 감속 방식 → 바퀴까지의 기계적 경로

- 실제 자동차 파워트레인에 사용되는 다양한 부품과 방식을 포함하였다.

### 2) 내연기관차 설명

- 동력 흐름:  
  **엔진 → 클러치 또는 토크컨버터 → 다단 변속기 → 최종감속기와 차동기어 → 바퀴**
- 엔진의 피스톤 왕복 운동이 크랭크축을 통해 회전 운동으로 변환된다.
- 엔진은 효율과 토크가 좋은 RPM 범위가 좁다.
- 따라서 여러 단의 기어비가 필요하다.
- MT, AT, DCT, CVT 등 다양한 변속기 방식을 언급하였다.
- AT는 토크컨버터와 유성기어 세트를 사용한다.
- DCT는 두 개의 클러치를 이용하여 변속하는 방식이다.

### 3) 전기차 설명

- 동력 흐름:  
  **배터리 → 인버터 → 전기모터 → 단일 감속기 → 차동기어 → 바퀴**
- 배터리의 직류 전원은 인버터를 통해 교류로 변환된다.
- 변환된 전력은 PMSM 또는 유도전동기와 같은 전기모터를 구동한다.
- 전기모터는 0 RPM부터 높은 토크를 발생시킬 수 있다.
- 넓은 RPM 범위에서 효율적으로 작동한다.
- 대부분 다단 변속기 없이 단일 감속기를 사용한다.
- 회생제동을 통해 감속 시 에너지를 회수할 수 있다.
- 회생제동은 브레이크 마모를 줄이는 효과도 있다.
- 일부 고성능 전기차에서는 예외적으로 2단 변속기를 사용할 수 있다고 설명하였다.

### 4) 하이브리드차 설명

- 엔진과 모터를 함께 사용하는 구조로 설명하였다.
- 대표적으로 파워스플릿 방식과 P2 하이브리드 방식을 제시하였다.
- 파워스플릿 방식에서는 유성기어 기반 동력분기장치를 사용한다.
- 동력분기장치는 엔진과 모터의 동력을 합치거나 나누는 역할을 한다.
- MG1과 MG2는 엔진 회전수 조절 또는 구동 토크 보완 역할을 수행한다.
- P2 하이브리드는 엔진과 모터가 클러치를 통해 연결된다.
- 기존 자동변속기나 DCT와 결합할 수 있다.
- 하이브리드차가 여러 종류의 파워트레인 구조를 가질 수 있음을 제시하였다.

### 5) 답변의 특징

- 다음과 같은 실제 자동차공학 용어를 다양하게 포함하였다.

  - 클러치
  - 토크컨버터
  - MT
  - AT
  - DCT
  - CVT
  - 최종감속기
  - 차동기어
  - PMSM
  - 유도전동기
  - 유성기어
  - MG1·MG2
  - P2 하이브리드

- 기계공학과 학생이 자동차 파워트레인을 이해하는 데 필요한 세부 요소가 풍부하였다.
- 세 모델 중 정확성, 기계공학 적합성, 구체성이 가장 높았다.
- 다만 부품 수와 동력 손실률 같은 일부 수치는 출처 없이 제시되었다.
- 해당 수치는 보고서에서 참고 수준으로 활용하는 것이 적절하다.
- 마지막 부분의 대화체 표현은 보고서용 문체로 수정할 필요가 있었다.

# 7. 최종 선정 및 결론

본 과업에는 **GPT-5**가 가장 적합한 모델로 선정되었다.

GPT-5는 내연기관 자동차, 전기자동차, 하이브리드 자동차의 동력 전달 경로를 설명하면서 다음과 같은 실제 자동차공학 구성 요소를 활용하였다.

- 클러치
- 토크컨버터
- 인버터
- 단일 감속기
- 다단 변속기
- 유성기어
- 차동기어
- PMSM
- MG1·MG2
- P2 하이브리드

이를 통해 다른 모델보다 답변의 전문성과 기계공학 적합성을 높였다.

Claude Haiku 4.5는 표와 그래프 활용 측면에서 GPT-5보다 우수한 모습을 보였지만, 일부 수치의 출처가 불명확했고 이모지와 대화체 표현 등 보고서 작성에 불필요한 요소가 포함되어 있었다.

Gemini 2.5 Pro는 전반적으로 이해하기 쉬운 답변을 제공하였지만, 변속기 종류와 하이브리드 방식에 대한 세부 설명이 상대적으로 부족하였다.

따라서 다음 요소를 종합적으로 고려하여 **GPT-5를 최종 모델로 선정하였다.**

1. 가장 높은 평균 평가 점수
2. 실제 자동차공학 용어와 구성 요소의 풍부한 사용
3. 내연기관차·전기차·하이브리드차의 구체적인 동력 전달 경로 설명
4. 기계공학 전공 수준에 적합한 분석 깊이
5. 후속 프롬프트 개선과 업무 자동화에 활용하기 적합한 답변 구조

> **최종 선정 모델: GPT-5**  
> **평균 점수: 4.6 / 5.0**
